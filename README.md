# ASP.NET Practice Archive

A collection of ASP.NET Core MVC practice projects completed during the 
Software Development program at Code Academy (Baku, Sept 2022 – Jan 2023). 
Each folder is a separate coursework exercise focused on a specific concept — 
EF Core relationships, Identity/roles, file uploads, admin panels, and 
multi-table CRUD operations.

These were stepping stones toward the program's final project, 
[Xhibiter NFT Marketplace](https://github.com/Ehtiram-Shukurov/nft-marketplace).

## Contents

- **Pronia** — E-commerce style MVC app with user registration, roles, and 
  file uploads.
- **bookshop-demo** — CRUD practice for managing books, categories, and 
  related entities.
- **crud-practice-1 (BizLand)** — Basic CRUD operations and form handling.
- **ef-core-practice (EFTask)** — Entity Framework Core relationship modeling 
  exercises.
- **shop-website-demo (MultiShop)** — Multi-vendor shop practice with 
  products, categories, colors, sizes, and discounts; the most developed 
  admin panel in this set.

> Note: these are archived coursework projects, not maintained or deployed.
